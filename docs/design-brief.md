# Design Brief — Project Edu (ชื่อชั่วคราว)

สรุปการตัดสินใจจากการ grill รอบ 1–3 (2026-11-03) ใช้เป็น input ให้ Researcher/Architect
คำศัพท์ทั้งหมดอ้างอิง [CONTEXT.md](../CONTEXT.md)

## Scope MVP

| เรื่อง | ตัดสินใจ |
|---|---|
| ผู้ใช้ | ม.ต้น + ม.ปลาย |
| วิชา | วิทยาศาสตร์ (ฟิสิกส์/เคมี/ชีวะ), คอมพิวเตอร์/AI/IoT, คณิตศาสตร์ |
| แพลตฟอร์ม | PWA มือถือก่อน, ภาษาไทย, ล็อกอิน Google |
| ครูที่ปรึกษา | เฟส 2 |
| ติดตามความคืบหน้า | เฟส 2 |

## Interview
- รูปแบบผสม: ฟอร์มทีละขั้น (ข้อมูลพื้นฐาน) + แชท AI (รายละเอียดไอเดีย / ถามต่อเมื่อข้อมูลไม่พอ)
- ถามทุกคน: ระดับชั้น, เป้าหมาย, เวลา/วันส่ง, งบ + อุปกรณ์, เดี่ยว/กลุ่ม, ทักษะ
- เป้าหมายที่รองรับ: งานแข่ง (YSC/NSC/ศิลปหัตถกรรม/ISEF), ส่งงานในชั้นเรียน, Portfolio/TCAS, ทำเพราะอยากทำ
- ระดับชั้นใช้กรองการ์ด + เลือก Rubric Preset

## Discovery Track
- Topic Card: ชุดที่ทีมคัด + AI สร้างเพิ่มจากการ์ดที่ปัดขวา
- Swipe: ← ข้าม / → สนใจ / ↑ อยากทำเลย + ย้อนกลับ
- สนใจครบ 5 ใบ → Shortlist เทียบแบบเคียงกัน → เลือก 1 → Idea

## Evaluation
- 5 ด้าน: ความใหม่, ความเป็นไปได้, ผลกระทบ, สมมติฐาน/วิธีวัดผล, ความเหมาะกับเป้าหมาย
- แสดงทั้งระดับสี 🟢🟡🔴 และคะแนน + เหตุผล + ข้อเสนอแนะต่อด้าน
- ติดแดง → แสดงงานที่คล้ายกัน + Pivot 2–3 แบบ → ประเมินซ้ำได้ (ไม่บล็อก)

## Output
- Proposal 1 หน้า + Plan รายสัปดาห์
