# 0008 — ซิงค์การปัด Shortlist และไอเดียแบบรวมทุกอุปกรณ์ และให้การเอาออกซิงค์ด้วย

- Status: Accepted
- Date: 2026-11-09

การปัด Shortlist ไอเดีย และการ์ดที่ AI คิด เป็นของบัญชีผู้เรียนและใช้ร่วมกันทั้งเว็บและมือถือ ซึ่งแก้ได้ตอนออฟไลน์บนหลายอุปกรณ์ จึงตัดสินใจให้การซิงค์รวมสิ่งที่เพิ่มจากทุกอุปกรณ์ (ไม่มีอะไรหายเพราะอีกเครื่องเขียนทับ) แต่การเอาออกเป็นการกระทำที่ซิงค์ด้วย ไม่ใช่แค่ไม่มีข้อมูล: แต่ละรายการเก็บการกระทำล่าสุดพร้อมเวลา แล้วการกระทำที่ใหม่กว่าชนะ การ์ดที่เอาออกจาก Shortlist จึงไม่กลับมาเองเมื่ออีกเครื่องซิงค์ของเก่าเข้ามา

## Considered Options
- **ใครแก้ล่าสุดชนะทั้งชุด**: ง่ายกว่า แต่ของที่เพิ่มบนอีกเครื่องตอนออฟไลน์หายได้
- **รวมทุกอย่างโดยไม่สนการเอาออก**: ไม่มีอะไรหาย แต่การ์ดที่เอาออกแล้วกลับมาเอง ผู้เรียนต้องเอาออกซ้ำ

## Consequences
- Shortlist อาจเกิน 5 ใบชั่วคราวหลังรวมจากหลายเครื่อง ผู้เรียนต้องเอาออกให้เหลือ 5 ที่หน้าเทียบก่อนเลือก
- ฝั่ง server ต้องเก็บการเอาออก (tombstone) ไว้ ไม่ลบแถวทิ้งทันที และการล้างข้อมูลตาม PDPA ยังต้องลบได้ครบ
