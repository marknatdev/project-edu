# 0003 — ต้องเข้าสู่ระบบด้วย Google ก่อนใช้แอป (ยกเลิก Guest Mode เมื่อมี Supabase)

- Status: Accepted
- Date: 2026-11-07

## Context

เดิม Design Brief และ CLAUDE.md กำหนดให้แอปใช้แบบ Guest ได้โดยไม่ต้องเข้าสู่ระบบ ส่วนบัญชี Google เป็นตัวเลือกเสริม และให้ผู้ใช้ที่เข้าสู่ระบบแล้วเลือกเองว่าจะทำงานในพื้นที่ Guest หรือพื้นที่บัญชี

ผู้ใช้ (เจ้าของผลิตภัณฑ์) สั่งเปลี่ยนเป็น "บังคับ OAuth login ก่อนเข้าใช้แอป" พร้อมหน้าแรกใหม่ ตามที่ออกแบบไว้ใน Figma (frame "00 · หน้าแรก · เข้าสู่ระบบ")

## Decision

ใช้กติกานี้เมื่อตั้งค่า Supabase ไว้ (`isSupabaseConfigured()`) ซึ่งเป็นเงื่อนไขที่ production ต้องมีอยู่แล้ว:

- **Middleware** (`src/middleware.ts`): ถ้าไม่มีผู้ใช้ที่ `getUser()` ยืนยันแล้ว จะ redirect 303 หน้าแอปไปที่ `/auth?next=<safeNext>`
  - หน้าที่เข้าได้โดยไม่ต้องเข้าสู่ระบบ:
    - `/auth/*` ซึ่งเป็นขั้นตอน OAuth เอง
    - `/api/*` ซึ่งตอบ 401 เป็น JSON เอง
    - `/share` และ `/advisor-review` ซึ่งเป็นลิงก์อ่านอย่างเดียวที่ส่งให้คนอื่น
    - `/consent` ซึ่งเป็นประกาศความเป็นส่วนตัว ต้องอ่านได้ก่อนเก็บข้อมูล
- **`resolvePrincipal`**: ถ้าไม่มี session จะ throw `401 AUTH_REQUIRED` และไม่ออก Guest capability ให้
  - ผู้ใช้ที่เข้าสู่ระบบแล้วเป็นพื้นที่บัญชีเสมอ (`decisionRequired: false`) ระบบไม่สนใจ cookie `edu-workspace=guest`
  - มีข้อยกเว้นเดียวคือ `guestOnly` ซึ่งยังใช้กับ `admitAuth` เพื่อจำกัดอัตราการขอเข้าสู่ระบบของคนที่ยังไม่ได้เข้าสู่ระบบ และใช้กับการลบข้อมูล Guest เดิมของเบราว์เซอร์ตอนผู้ใช้กดลบข้อมูล
- **`/auth`**: เป็นหน้าแรกที่ให้เข้าสู่ระบบ ส่วนหน้าต่าง `AccountButton` ยังแจ้งเรื่องการประมวลผลชื่อและอีเมลโดย Google/Supabase ก่อนกดยินยอม
- **ถ้าไม่ได้ตั้งค่า Supabase** (ตอนพัฒนาบนเครื่องและเทสต์ส่วนใหญ่): ทำงานแบบ Guest เหมือนเดิม เพราะไม่มีระบบเข้าสู่ระบบให้ใช้

## Consequences

- งาน Guest เดิม ทั้งในเครื่องและบนเซิร์ฟเวอร์ที่ผูกกับ `g:` owner จะไม่แสดงหลังเข้าสู่ระบบ และไม่ถูกคัดลอกเข้าบัญชีตามข้อห้ามเดิม แต่ยังลบได้จากหน้าความเป็นส่วนตัวหลังเข้าสู่ระบบ
- route `/auth/workspace` และ cookie `edu-workspace` ไม่มีผลต่อความเป็นเจ้าของแล้ว จึงเป็นโค้ดค้างที่ควรลบในงานถัดไป
- ข้อมูลส่วนบุคคล (ชื่อ อีเมล) ถูกประมวลผลโดย Google/Supabase สำหรับผู้ใช้ทุกคน รวมถึงผู้เยาว์
  - ต้องทบทวนอายุขั้นต่ำของบัญชี Google และความยินยอมของผู้ปกครองตาม PDPA ก่อนเปิดใช้จริง
  - สิ่งที่แอปเก็บยังคงเดิม: เก็บแค่รหัสบัญชี ไม่คัดลอกชื่อหรืออีเมล
