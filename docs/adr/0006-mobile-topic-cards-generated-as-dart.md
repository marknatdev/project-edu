# 0006 — คลัง Topic Card บนมือถือสร้างเป็นโค้ด Dart จากข้อมูลของเว็บ

- Status: Accepted
- Date: 2026-11-09

คลัง Topic Card มีแหล่งเดียวคือ `src/data/cards/*.ts` ของเว็บ ฝั่งมือถือไม่เขียนการ์ดเองและไม่โหลดเป็นไฟล์ JSON แต่ใช้สคริปต์แปลงข้อมูลชุดนั้นเป็นไฟล์ Dart ที่สร้างอัตโนมัติ เหตุผลคือ Shorebird patch อัปเดตได้เฉพาะโค้ด Dart ไม่รวมไฟล์ asset ถ้าเก็บการ์ดเป็น JSON การแก้การ์ดจะต้องออก release ใหม่และให้ผู้ใช้ติดตั้งใหม่ทุกครั้ง ส่วนการเก็บไว้บน server ต้องมีเน็ตตั้งแต่ครั้งแรกและต้องเพิ่ม table กับ migration

## Consequences
- แก้การ์ดที่ `src/data/cards/*.ts` แล้วรันสคริปต์สร้างไฟล์ Dart ใหม่ ห้ามแก้ไฟล์ Dart ที่สร้างขึ้นด้วยมือ
- ต้องมี test ฝั่งเว็บหรือมือถือที่ตรวจว่าไฟล์ Dart ตรงกับข้อมูลต้นทาง เพื่อไม่ให้สองฝั่งค่อย ๆ ไม่ตรงกัน
