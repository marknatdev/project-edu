# 0004 — แชตครูที่ปรึกษาใช้โหมดสนทนาแทนบันไดความช่วยเหลือ 3 ระดับ

- Status: Accepted
- Date: 2026-11-07
- Supersedes: ส่วน "3 ระดับ (Progressive Scaffolding)" และ "Clarification — เกณฑ์ขอตัวอย่างระดับ 3" ของ ADR 0002 **เฉพาะแชตครูที่ปรึกษา** (`/api/ai/coach`)

## Context
ระหว่างออกแบบ UI ใหม่ (Design System v2) ผู้ใช้ตัดสินใจให้แชตกับ AI เป็นปุ่มหลักตรงกลางแถบแท็บบนมือถือ และเปลี่ยนปุ่ม 3 ปุ่มด้านบนของแชต (คำถาม / คำใบ้ / ตัวอย่าง) เป็นตัวเลือกโหมดแบบเดียวกับแอปแชต AI ทั่วไป ผู้ใช้เลือกให้ "โหมดแทนบันได" ไม่ใช่ซ้อนบนบันไดเดิม

## Decision
แชตครูที่ปรึกษามี 4 โหมด ผู้เรียนเลือกได้ทุกเมื่อ ค่าเริ่มต้นคือ "อัตโนมัติ"

| โหมด | สิ่งที่ AI ทำ | สิ่งที่ห้าม |
|---|---|---|
| ถาม (`ask`) | ตอบเรื่องโครงงานด้วยคำถามชวนคิดเป็นหลัก ช่วยให้ผู้เรียนนิยามปัญหา วัตถุประสงค์ วิธีการ และการวัดผลเอง | เขียนโครงงานแทนผู้เรียน |
| ช่วยค้นคว้า (`research`) | สอนว่าจะค้นอะไร ค้นที่ไหน และอ่านอย่างไร แสดงงานที่เกี่ยวข้อง **เฉพาะ** จากชุดข้อมูลคัดสรร `src/data/prior-work.ts` | สร้างหรืออ้างแหล่งข้อมูล ลิงก์ หรืองานวิจัยที่ไม่อยู่ในชุดข้อมูล (เซิร์ฟเวอร์ตัด URL จากข้อความ AI และแนบรายการตาม ID เท่านั้น) |
| คิดไอเดีย (`ideate`) | ระดมความคิดผ่านคำถาม และเสนอทิศทางสั้น ๆ เป็น **จุดตั้งต้น** ให้ผู้เรียนคิดต่อ | นำเสนอเป็นโครงงานสำเร็จรูป |
| อัตโนมัติ (`auto`) | เลือกหนึ่งในสามโหมดข้างต้นจากข้อความของผู้เรียน (ค่าเริ่มต้น: ถาม) | — |

สิ่งที่ยังคงไว้จาก ADR 0002:
- AI ไม่เขียนโครงงานแทนผู้เรียน และการเลือกแนวทางจาก AI ต้องผ่านขั้น "เขียนด้วยภาษาของตัวเอง" (RewriteGate) ก่อนบันทึกเป็นไอเดียหรือนำไปทำ Proposal
- Topic Card เป็นจุดตั้งต้น ไม่ใช่โครงงานสำเร็จรูป และไม่ใช้คำว่า verified
- ความเป็นเจ้าของบทสนทนา, CAS revision, idempotency receipt และการลบข้อมูลยังเหมือนเดิม
- Pivot Workshop (`/api/ai/pivot`) ยังใช้บันได 3 ระดับตามเดิม ADR นี้ไม่ครอบคลุม

## Consequences
- ปุ่มขอระดับ 2/3 และการล็อกตัวอย่างในแชตถูกนำออก เซิร์ฟเวอร์ไม่ตรวจหลักฐานปลดล็อกระดับ 3 สำหรับแชตอีกต่อไป
- คำขอ `turn` เพิ่มฟิลด์ `mode` (ไม่บังคับ) และรวมในลายนิ้วมือ receipt; ข้อมูลบทสนทนาเดิมที่มี `tier` ใน history ยังอ่านได้
- ความเสี่ยง: ผู้เรียนอาจใช้โหมดคิดไอเดียแทนการคิดเอง จึงต้องคง RewriteGate และให้กรรมการ/ครูเห็นว่าไอเดียมาจากการคุยกับ AI ผ่านเอกสารส่งออกตามเดิม
- โหมดอัตโนมัติใช้ตัวจำแนกแบบกำหนดแน่นอน (คำสำคัญ) ก่อน หากต้องการความแม่นยำกว่านี้จึงเปลี่ยนเป็นให้ AI เลือก
